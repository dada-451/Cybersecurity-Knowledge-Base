# 安全实验记录

实验记录遵循以下原则：

- **可复现**：尽可能保留实验环境、命令、分析脚本和验证过程。
- **有证据**：区分已验证结论、推测和待验证问题。
- **重理解**：不只记录最终答案，更注重分析思路与技术原理。
- **持续完善**：允许先建立实验索引，再逐步补充完整报告。
